# Pembantu Pembinaan dan Penyelarasan Rubrik

Panduan pengguna untuk pakej Kemahiran.AI `design-moderate-rubrics`.

## Cara menggunakan dalam Gemini

1. Muat naik pakej ZIP melalui Gemini `Customize → Skills → Create → Upload`.
2. Sediakan hasil pembelajaran, tugasan, tahap murid, struktur rubrik dan peraturan pemarkahan yang diluluskan.
3. Gunakan respons contoh yang dinyahkenal pasti untuk percubaan atau penyelarasan.
4. Guru menentukan deskriptor akhir, pemberat dan keputusan pentaksiran.

`SKILL.md` ialah spesifikasi operasi dalam English untuk keserasian alat dan menetapkan Bahasa Melayu sebagai bahasa lalai. Kemahiran membantu mereka dan menguji draf rubrik; ia tidak memberikan gred akhir kepada murid sebenar.

## English

Upload the ZIP package through Gemini `Customize → Skills → Create → Upload` and provide the learning outcomes, assessed task, learner level, rubric structure and approved marking rules. Use only de-identified sample responses for trialling or moderation. The operational file is in English for portability but requests Malay output by default. The teacher remains responsible for final descriptors, weighting and assessment decisions.
