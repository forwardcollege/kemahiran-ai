# Optional organisational template setup

## Bahasa Melayu

Pakej generik ini tidak mengandungi templat, minit sebenar atau panduan sulit organisasi.

Jika organisasi mempunyai format minit yang diluluskan:

1. Gunakan hanya templat kosong atau panduan gaya yang dibenarkan untuk AI.
2. Buang nama, kehadiran, keputusan, tindakan dan metadata daripada mesyuarat terdahulu.
3. Pastikan fail rujukan menerangkan struktur dan gaya sahaja; ia bukan bukti bagi mesyuarat baharu.
4. Simpan nota mesyuarat semasa sebagai input tugasan berasingan, bukan pengetahuan kekal Skill.
5. Uji bahawa Skill menandakan fakta yang hilang dan tidak menyalin keputusan daripada templat lama.

## English

This generic package contains no organisational template, real minutes or confidential guidance.

When an organisation has an approved minutes format:

1. Use only a blank template or style guide authorised for AI use.
2. Remove names, attendance, decisions, actions and metadata from previous meetings.
3. Confirm that the reference defines structure and style only; it is not evidence for a new meeting.
4. Keep current meeting notes as separate task input, not persistent Skill knowledge.
5. Test that the Skill marks missing facts and does not copy decisions from an old template.
