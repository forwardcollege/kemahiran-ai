# Pembantu Penyediaan Minit Mesyuarat Formal

Panduan pengguna untuk pakej Kemahiran.AI `draft-formal-meeting-minutes`.

## Cara menggunakan dalam Gemini

1. Muat naik pakej ZIP melalui Gemini `Customize → Skills → Create → Upload`.
2. Sediakan nota mesyuarat yang lengkap dan telah dinyahkenal pasti.
3. Nyatakan butiran mesyuarat yang disahkan serta format organisasi jika ada.
4. Pengerusi atau urus setia mesti mengesahkan perbincangan, keputusan, tindakan, pemilik dan tarikh sebelum edaran.

Baca `references/template-setup.md` jika organisasi menggunakan templat khusus. `SKILL.md` ditulis dalam English sebagai spesifikasi operasi mudah alih tetapi menetapkan Bahasa Melayu sebagai bahasa lalai. Jangan masukkan nota sulit, nombor pengenalan, butiran kes atau data hubungan peribadi.

## English

Upload the ZIP package through Gemini `Customize → Skills → Create → Upload` and provide complete, de-identified meeting notes plus verified meeting details. Read `references/template-setup.md` when an organisational template applies. The operational file is in English for tool portability but requests Malay output by default. The chair or secretariat must verify discussions, decisions, actions, owners and dates before circulation.
