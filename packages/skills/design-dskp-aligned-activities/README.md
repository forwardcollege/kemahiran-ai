# Pereka Aktiviti Pembelajaran Berasaskan DSKP

Panduan pengguna untuk pakej Kemahiran.AI `design-dskp-aligned-activities`.

## Cara menggunakan dalam Gemini

1. Tambahkan `SKILL.md` sebagai arahan Kemahiran atau Gem.
2. Lampirkan PDF DSKP rasmi atau petikan yang boleh dikenal pasti.
3. Nyatakan Standard Kandungan atau Standard Pembelajaran sasaran, masa, konteks umum kelas dan senarai tertutup bahan serta kemudahan.
4. Sahkan rujukan DSKP yang dikenal pasti sebelum aktiviti dijana.

`SKILL.md` ditulis dalam English sebagai spesifikasi operasi mudah alih tetapi menetapkan Bahasa Melayu sebagai bahasa lalai. Jangan masukkan maklumat pengenalan murid. Guru mesti menyemak keselamatan, kebolehlaksanaan, pembezaan dan kesetiaan kepada sumber rasmi.

## English

Add `SKILL.md` as the Skill or Gem instruction and attach an official DSKP PDF or identifiable extract. State the exact target standard, duration, general class context and closed list of available materials and facilities. The operational file is in English for portability but requests Malay output by default. Confirm the cited DSKP reference before generation and review safety, feasibility, differentiation and source fidelity.
