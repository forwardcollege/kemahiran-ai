# Pembina Panduan Respons Khidmat Pelanggan

Panduan pengguna untuk pakej Kemahiran.AI `build-customer-service-playbook`.

## Cara menggunakan dalam Gemini

1. Tambahkan `SKILL.md` sebagai arahan Kemahiran atau Gem.
2. Sediakan dasar perkhidmatan, pemulangan, bayaran balik, privasi dan eskalasi yang diluluskan.
3. Berikan senario pelanggan yang telah dinyahkenal pasti dan saluran komunikasi sasaran.
4. Minta pemilik dasar menyemak corak respons, had kuasa dan pencetus eskalasi.

`SKILL.md` ditulis dalam English sebagai spesifikasi operasi mudah alih tetapi menetapkan Bahasa Melayu sebagai bahasa lalai. Jangan masukkan data pelanggan sebenar atau benarkan AI menjanjikan pampasan, tarikh, pengecualian atau hasil tanpa kuasa.

## English

Add `SKILL.md` as the Skill or Gem instruction and provide approved service, return, refund, privacy and escalation policies. Use de-identified scenarios and state the target channels. The operational file is in English for portability but requests Malay output by default. A policy owner must approve response patterns, authority limits and escalation triggers; never include real customer data or unauthorised promises.
