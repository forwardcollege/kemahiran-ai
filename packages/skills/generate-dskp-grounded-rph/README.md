# Penjana Rancangan Pengajaran Harian Berpandukan DSKP

Panduan pengguna untuk pakej Kemahiran.AI `generate-dskp-grounded-rph`.

## Cara menggunakan dalam Gemini

1. Tambahkan `SKILL.md` sebagai arahan Kemahiran atau Gem.
2. Ikuti `references/knowledge-setup.md` untuk menambah PDF DSKP rasmi yang sepadan.
3. Nyatakan mata pelajaran, tahun atau tingkatan, standard sasaran, tempoh, konteks umum murid serta senarai tertutup sumber dan kemudahan.
4. Sahkan rujukan DSKP sebelum meminta draf RPH, kemudian semak masa, keselamatan, pembezaan dan pentaksiran.

`SKILL.md` ditulis dalam English sebagai spesifikasi operasi mudah alih tetapi menetapkan Bahasa Melayu sebagai bahasa lalai. Pakej ini tidak mengandungi PDF DSKP rasmi. Jangan masukkan data pengenalan murid, dan jangan benarkan AI mencipta kod atau pernyataan standard.

## English

Add `SKILL.md` as the Skill or Gem instruction and follow `references/knowledge-setup.md` to attach the matching official DSKP PDF. State the subject, year or form, target standard, duration, general learner context and closed list of resources and facilities. The operational file is in English for portability but requests Malay output by default. Confirm the DSKP reference before drafting and review timing, safety, differentiation and assessment.
