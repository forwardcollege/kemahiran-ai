# Penjana Kertas Kerja Program

Panduan pengguna untuk pakej Kemahiran.AI `draft-programme-paper`.

## Cara menggunakan dalam Gemini

1. Tambahkan `SKILL.md` sebagai arahan Kemahiran atau Gem.
2. Sediakan tujuan, peserta sasaran, hasil, aktiviti, jadual, tadbir urus dan laluan kelulusan.
3. Berikan angka bajet, indikator dan format organisasi hanya apabila telah disahkan.
4. Pegawai berkuasa menyemak kewangan, perolehan, keselamatan, dasar dan kelulusan sebelum penghantaran.

`SKILL.md` ialah spesifikasi operasi dalam English untuk keserasian alat dan menetapkan Bahasa Melayu sebagai bahasa lalai. Templat ialah panduan struktur sahaja; ia bukan bukti fakta, harga, penaja atau kuasa melulus.

## English

Add `SKILL.md` as the Skill or Gem instruction and provide the purpose, intended participants, outcomes, activities, schedule, governance and approval route. Supply budget figures, indicators and organisational formatting only when verified. The operational file is in English for portability but requests Malay output by default. An authorised officer must review finance, procurement, safety, policy and approvals before submission.
