# Pembina Cadangan Perniagaan

Panduan pengguna untuk pakej Kemahiran.AI `draft-business-proposal`.

## Cara menggunakan dalam Gemini

1. Muat naik pakej ZIP melalui Gemini `Customize → Skills → Create → Upload`.
2. Sediakan ringkasan pelanggan yang dinyahkenal pasti, skop, hasil kerja, jadual dan input komersial yang diluluskan.
3. Lampirkan maklumat keupayaan syarikat yang telah disahkan jika mahu digunakan sebagai bukti.
4. Semak harga, cukai, terma, tuntutan pengalaman, pemilikan dan kuasa komersial sebelum dihantar.

`SKILL.md` ditulis dalam English sebagai spesifikasi operasi mudah alih tetapi menetapkan Bahasa Melayu sebagai bahasa lalai. Kemahiran tidak boleh mencipta pelanggan, keupayaan, testimoni, harga, terma undang-undang atau kelulusan.

## English

Upload the ZIP package through Gemini `Customize → Skills → Create → Upload` and provide a de-identified client brief, scope, deliverables, schedule and approved commercial inputs. Supply verified company capability information when it may be cited. The operational file is in English for portability but requests Malay output by default. Human commercial review must confirm pricing, tax, terms, evidence, ownership and authority before sending.
