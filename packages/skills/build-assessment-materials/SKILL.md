# Build assessment materials

Create teacher-reviewable questions and an answer scheme grounded only in supplied teaching content.

## Required inputs

Require:

- authorised source content;
- learning outcomes and learner level;
- question quantity and formats;
- expected completion time;
- intended difficulty distribution;
- language and accessibility requirements; and
- marking approach.

When official DSKP alignment is requested, also require an identifiable official source and obtain confirmation of the exact standard. If a required input is missing, ask no more than five critical questions and stop. Do not draft a full set using invented defaults.

## Workflow

1. Summarise the permitted source boundary and target outcomes.
2. Propose a blueprint mapping each planned item to an outcome, thinking demand, format and mark allocation.
3. Check the blueprint against the requested total, time and difficulty distribution.
4. Produce a learner version without answers, hidden clues or teacher notes.
5. Produce a separate scheme with the expected answer, brief source-grounded rationale, marks and valid alternatives where applicable.
6. Audit every item for source fidelity, level-appropriate language, one best answer or explicit open criteria, accidental clues, duplication, bias, accessibility and realistic completion time.
7. Repair supported issues. Mark unresolved matters `[PERLU SEMAKAN GURU]` or `[TEACHER REVIEW REQUIRED]`.
8. Finish with an unchecked teacher-verification list.

## Boundaries

- Do not add facts, examples or answers from memory beyond the supplied content.
- Every factual term in a stem, option and answer must be supported by the source. If source-only multiple-choice distractors are not possible, change the item format or request additional authorised content.
- Keep difficulty labels out of the learner paper unless the teacher explicitly requests them.
- Audit language must remain provisional: say that no obvious issue was detected in the draft and teacher review is still required. Never certify absence of ambiguity, bias or timing problems.
- Do not claim DSKP alignment without an identified source.
- Do not use real learner names, responses, marks or records.
- Do not grade, rank, diagnose or predict individual learner ability.
- Do not reproduce protected examination items or substantial copyrighted material unless the user confirms permission.
- Do not claim the set is validated, fair, standardised or error-free.
- Do not create a high-stakes assessment without qualified human review.

Write in Bahasa Melayu by default and in English when requested.
