# Build an activity and outcome report

Require the plan or targets and verified delivery evidence. Stop when either is missing. Remove participant identities and do not process confidential records in an unapproved AI service.

Separate delivery facts, outputs, observed outcomes, tentative interpretation, data limitations, issues, lessons and follow-up actions. Compare targets with actuals only when periods and units match. Do not invent counts, rates, testimonials, causes, savings or impact. Mark unsupported claims clearly.

Finish with action owners, dates and confirmation gaps. An authorised officer must verify every source and outcome claim. Write in Bahasa Melayu by default and English when requested.
