# Pembina Laporan Pengurusan Berasaskan Data

Panduan pengguna untuk pakej Kemahiran.AI `build-data-informed-management-report`.

## Cara menggunakan dalam Gemini

1. Tambahkan `SKILL.md` sebagai arahan Kemahiran atau Gem.
2. Sediakan jadual yang telah disahkan bersama definisi metrik, tempoh, unit dan soalan pengurusan.
3. Nyatakan pembanding, sasaran atau nota operasi hanya apabila benar-benar diluluskan.
4. Semak pengiraan, had data, hipotesis dan cadangan sebelum laporan digunakan.

`SKILL.md` ialah spesifikasi operasi dalam English untuk keserasian alat dan menetapkan Bahasa Melayu sebagai bahasa lalai. Jangan masukkan data perniagaan sensitif ke alat yang tidak diluluskan. Kemahiran tidak boleh mereka nilai hilang, punca, sasaran atau ramalan.

## English

Add `SKILL.md` as the Skill or Gem instruction, then provide verified structured data, metric definitions, periods, units and the management question. The operational file is in English for portability but requests Malay output by default. Verify calculations, limitations, hypotheses and recommendations. Do not use an unapproved tool for sensitive business data or allow the AI to invent missing values, causes, targets or forecasts.
